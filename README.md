
# Paradise Nursery 🌿

## Project Name
Paradise Nursery Plant Shop

## Project Description
Paradise Nursery is a React-based plant shopping application
that allows users to explore plants and manage their shopping cart.

## Features
- Landing page with a Get Started button
- About Us section
- Plant product listing
- Add plants to shopping cart
- Update product quantities
- Remove plants from cart
- View cart total

## Technologies Used
- React
- Vite
- Redux Toolkit
- React Redux
- React Router

## Installation
1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
