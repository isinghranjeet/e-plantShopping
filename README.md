# Paradise Nursery 🌿

## Project Name
Paradise Nursery Plant Shop

## Project Description
Paradise Nursery is a React-based plant shopping application that allows users to explore different plants, view product details, and manage their shopping cart.

## Features
- Landing page with a Get Started button
- About Us section with company information
- Plant product listing organized by categories
- Plant images, names, descriptions, and prices
- Add plants to the shopping cart
- Increase and decrease product quantities
- Remove plants from the shopping cart
- View individual item subtotals
- View total cart amount
- Continue shopping from the cart page

## Technologies Used
- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- JavaScript
- CSS

## Installation and Setup
1. Clone this repository:
   `git clone https://github.com/isinghranjeet/e-plantShopping.git`
2. Navigate to the project directory:
   `cd e-plantShopping`
3. Install dependencies:
   `npm install`
4. Start the development server:
   `npm run dev`
